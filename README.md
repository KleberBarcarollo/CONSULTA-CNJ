# CONSULTA-CNJ
CONSULTA CNJ
Este fluxo permite realizar a consulta de acompanhamentos processuais no site do CNJ usando os filtros da página.
Sobre este fluxo de automação:
Realize a consulta no site https://comunica.pje.jus.br/consulta?siglaTribunal=TJPR através de critérios de data e nome do advogado.
A Coleta é feito do primeiro processo, mas pode ser adaptado conforme a sua necessidade.

Tipo: Web
Navegador: Chrome
